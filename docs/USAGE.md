# 使用指南

本文说明管理台的日常操作、资料模型、上传规则、AI 识别、搜题和状态含义。安装与配置见 [DEPLOYMENT.md](DEPLOYMENT.md)，接口字段见 [API.md](API.md)，技术数据流见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 1. 首次使用

1. 使用首次启动时配置的管理员账号登录。
2. 在「用户」中创建 `editor` 或 `viewer` 账号，按需分配权限。
3. 在「存储端点」中检查默认本地端点；需要多点存储时添加云盘或对象存储端点并测试连接。
4. 在「副本策略」中设置最低就绪副本数和各端点用途。
5. 在任意页面点击「上传资料」开始归档。

## 2. 资料模型

| 对象 | 作用 |
| --- | --- |
| 套卷 | 浏览和编目单位。学科、年级、届别、地区、机构、类型、标签和描述保存在套卷上 |
| 文件 | 一份逻辑内容。记录部件、答案起始页和在套卷中的顺序 |
| 源记录 | 同一内容从不同上传路径到达时追加来源，不复制原件 |
| 专题 | 把套卷按复习主题重新组合，不改变套卷内容 |
| 回收站 | 保存已删除的套卷和文件 30 天，可恢复或彻底删除 |

文件部件包括试题、答案、教师版、答题卡、听力和正文。文件从所属套卷继承编目信息；套卷标题人工编辑后会锁定，不再被自动识别覆盖。

同一 SHA-256 只归档一次。重复上传会显示为秒传或追加来源记录，不重复解析、索引和复制副本。

## 3. 上传与归档

### 选择内容

- 单个普通文件会生成一个套卷。
- 文件夹中的文件逐个传输并保留相对路径。
- 同一目录内主干相同的文件会合并为一个套卷，例如 `数学-试卷.pdf` 与 `数学-答案.pdf`。
- ZIP 由服务端安全展开，成员按展开后的路径分组；ZIP 原件本身不进入资料库。
- 支持上传 PDF、DOC、DOCX、PPT、PPTX、XLS、XLSX、常见图片和音频；文件真实格式必须与扩展名一致。

选择完成后会立即创建上传清单并开始传输，无需先填写完整表单。管理台会按文件名尽量推断标题、学科和类型，不确定的字段留空，归档后可编辑。

### 上传限制

- 一个清单最多 2000 个文件。
- 单个文件最大 512 MiB。
- 一批文件总大小最大 2 GiB。
- 每个 ZIP 最多展开 5000 个非忽略文件，声明展开总大小不超过 2 GiB。
- ZIP 中只归档 PDF、DOC、DOCX、PPTX 和嵌套 ZIP；其他成员会跳过并提示。
- 整个 ZIP 链最多展开 3 层；超过上限的嵌套包按不支持成员跳过。

服务端拒绝路径穿越、绝对路径、符号链接、重复路径、加密 ZIP、格式伪装和解压炸弹，并尝试还原 GB18030、Big5 或 Shift-JIS 文件名。

全部文件接收后会自动提交归档。关闭页面或网络中断时，可在「上传记录」中重新选择未完成文件或重试失败项；已接收内容无需重传。

### 归档后

归档、副本上传、AI 识别、题目索引和自动归类是独立任务。识别、索引或归类失败不会影响原件归档与下载。

文件详情支持下载原件，预览 PDF 和 DOCX。DOCX 首次预览或「下载 PDF」会由服务端转换并缓存；复杂版式、公式和缺失字体可能与 Word 显示不同，加密文档和外部引用资源需要先在本地处理。

## 4. 整理资料库

- 「待整理」用于确认低置信度、带配套建议或未开启自动识别的文件。
- 「资料库」可按编目字段筛选套卷，查看文件、预览原件、调整顺序、批量编辑或打包下载。
- 单文件试卷可在识别后自动匹配已有套卷；确认建议时可选择接受配套。
- 「专题」只建立套卷收录关系。删除专题不会删除套卷；合并套卷时已有专题收录会保留。
- 删除套卷或文件会进入回收站。彻底删除会清理文件、来源、专题收录、解析缓存、题目索引和本地副本，但不会删除云盘上的远端对象。

## 5. AI 识别与自动编目

### 配置

1. 管理员在「AI 模型」中添加 OpenAI 兼容端点，填写 Base URL 和 API Key，并运行探测或最小对话测试。
2. 在「AI 解析」中选择 OCR 服务商。
3. 自建 Compose 推荐使用 `RapidOCR（自建）`，地址为 `http://rapidocr:9003`，无需令牌。
4. PaddleOCR 和 MinerU 需要填写各自服务地址与令牌。
5. 按需开启「自动识别」。

存储、AI 和 OCR 凭据使用 `MASTER_KEY` 加密保存；接口只返回是否已配置，不回显密钥。

### 识别行为

归档后启用自动识别时，每个非 ZIP 文件会自动入队。服务端先解析正文或页面图像，再由模型生成编目和部件建议；标题、学科、年级、届别、地区、机构、类型、标签、部件和答案起始页通过白名单校验后自动应用，并同步文件名。

归类依据正文，文件名和来源路径只作辅助；正文与文件名冲突时以正文为准。长文档会保留开头和末尾，避免遗漏卷末答案区。没有解析出正文或图像时任务失败，不按文件名猜测。

文件详情可查看识别状态、置信度、解析文本和已应用结果。人工可以编辑编目与部件，也可以「重新应用建议」或重新运行识别。

RapidOCR 可直接读取 DOCX 的段落、标题、表格、文本框、公式和分页提示，并对嵌入图片执行 OCR。图片有数量和体积上限；单张图片失败不会丢失正文。页码来自显式或渲染分页，没有分页提示的连续文档按第 1 页处理。

### 自动配套

单文件试卷完成识别后会尝试匹配已有套卷：

- 相似度至少 70，且领先第二名至少 15 时自动并入。
- 相似度至少 40 时进入待整理并给出建议。
- 更低分时保持独立。

系统不会自动创建专题，也不会自动改写套卷的专题归属。

## 6. 搜题

「搜题」输入题干或公式后，会返回题目、命中高亮、页码、原试卷和所属套卷。PDF 可打开并定位到对应页；非 PDF 原件跳转到文件详情。

索引默认启用，但需要可用的 OCR 与模型。只有部件为“试题”或“试卷+答案”的文件会自动入队；部件变化后，系统会同步创建或清理索引。关闭索引期间归档的试卷文件会在重新启用后补建。

公式搜索支持常见文本和 LaTeX 写法，例如 `x+y`、`x²+1`、`x^{2}+1` 与 `\frac{x}{y}`；支持符号写法归一化，不进行通用代数等价推导。当前 RapidOCR 未接入扫描件公式识别模型。

文件详情的「题目索引」可查看题目、页码、置信度和状态。索引失败不影响归档与下载；重建失败时旧索引仍可查询。

## 7. 角色、状态与任务

| 角色 | 主要权限 |
| --- | --- |
| `admin` | 全部权限，包括用户、密钥、存储、AI、审计和系统配置 |
| `editor` | 读写套卷、文件、专题，上传资料并查看任务 |
| `viewer` | 只读套卷、专题和任务 |

API 密钥的有效权限是密钥授权范围与所属用户当前角色权限的交集。撤销密钥或禁用用户后，后续请求立即失效。

常见上传状态：

```text
pending → processing → completed / failed
```

文件整理阶段：

- `processing`：识别中。
- `review`：待整理。
- `ready`：已入库。
- `failed`：识别失败。

副本状态：

- `archived`：达到策略要求的最低就绪副本数。
- `degraded`：没有就绪或进行中的副本，且存在失败副本。
- `pending_storage`：正在等待副本满足策略。

任务状态为 `pending → running → succeeded / failed`。在「处理日志」中可查看归档、复制、识别和索引进度；具有 `jobs:write` 权限的用户可以重试失败任务。

## 8. 观测与 Agent 接入

顶栏「网络」在浏览器会话内采集最近的 API、上传和下载请求，显示 P95、平均值、中位数、成功率、传输量、在途请求、响应大小和 request ID。采样只存在内存，不记录正文、凭据或查询参数。

后端日志对每个 `/api/*` 和 `/mcp` 请求记录方法、路径、状态、耗时、响应字节数和 request ID，不记录查询参数、请求体或响应正文。

管理员可为 Agent 创建最小权限 API 密钥。REST 和 MCP 都使用 `Authorization: Bearer <密钥>`；密钥明文只在创建时显示一次。MCP 客户端配置、工具和上传下载方式见 [MCP 接入指南](MCP.md)。
